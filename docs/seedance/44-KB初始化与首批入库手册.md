# 44-KB初始化与首批入库手册

更新时间：2026-05-13

本文档对应 Prompt Optimizer 的前置条件：先初始化 `KB-01-规则库` 与 `KB-02-模板库`，再使用优化模式。

## 1. 准备

1. 启动 OpenWebUI（dev 或 prod 实例均可）。
2. 准备管理员 Token（用于创建 KB、上传文件、重建索引）。
3. 确认首批 seed 文件目录：
   - `scripts/seedance/kb-seeds/KB-01`
   - `scripts/seedance/kb-seeds/KB-02`

## 2. 执行初始化

```bash
python scripts/seedance/init_prompt_optimizer_kb.py \
  --base-url http://127.0.0.1:8802 \
  --token "$OPENWEBUI_TOKEN"
```

可选参数：

1. `--seed-root`：自定义种子目录根路径。
2. `--skip-reindex`：跳过重建索引（不建议首次使用）。

## 3. 脚本行为

脚本会按顺序执行：

1. 确保存在 `KB-01-规则库`、`KB-02-模板库`（存在则复用）。
2. 上传目录下 `.md` 文件并关联到对应 KB。
3. 跳过 KB 中同名已存在文件。
4. 默认执行：
   - `POST /api/v1/knowledge/reindex`
   - `POST /api/v1/knowledge/metadata/reindex`

## 4. 验收建议

1. 在 WebUI Knowledge 页面确认两个 KB 存在且文件数量正确。
2. 任选 3 条规则关键词进行检索，确认能命中 KB-01。
3. 任选 3 条模板关键词进行检索，确认能命中 KB-02。
4. 再启用优化模式，检查 `kb_trace.evidence_count >= 2`。

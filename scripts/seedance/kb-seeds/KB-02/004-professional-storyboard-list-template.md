## 使用约束

1. 仅在用户显式要求模板输出时使用本模板。
2. 模板中无法从素材确认的信息，统一填写 `[待补充]`。
3. 禁止编造素材中未观察到的内容。
4. 输出字段顺序必须与模板一致。
5. 如果用户要求“仅输出部分维度”，可只输出相关字段块。

## 输出模板

### 专业视频分镜脚本模板
#### 提交 API 请求时，要求对方 LLM 按模版输出

##### 一、核心基础信息
- 视频类型：[剧情短片/品牌广告/产品宣传片/科普视频/短视频（抖音/小红书）/其他]
- 总时长：[如：45 秒]
- 核心主题：[一句话概括核心表达，如："通过职场新人的成长，传递品牌陪伴理念"]

##### 二、整体场景设定
- 场景概况：[一句话概括，如："美国高中放学时的教学楼走廊"]
- 环境描述：[详细环境描述，包含各种画面中可见的建筑，物体，氛围等...]

##### 三、专业人物设定
- 人物ID：1 - N
- 人物名称：[女1 / 男 1/ 男 2...]
- 年龄/性别：[如：24岁/女]
- 外貌特征：[如：种族，发型，发色，服饰，配饰，气质...]
- 性格标签：[如：内敛细心、有韧性...]

##### 四、分镜详细内容
- 镜号：1 - N
- 景别：[如：全景 / 中景/ 特写...]
画面内容：[女1 / 男 1/ 男 2...][动作，例如：“站在公司楼下，抬头看写字楼玻璃幕墙，双手紧紧攥着简历袋，脚- 步犹豫”]
- 运镜方式：[如：固定镜头（轻微向上摇）/ 跟镜头（如：从[男 1]转向[女2]）...]
- 时长：[如：5秒]
- 台词/旁白：[如：[女1]: / 旁白："24岁的林晓，第一次走进这家她向往已久的公司"]
- 音效：[如：城市背景音+轻微的心跳声 / 会议室安静背景音+笔尖摩擦声]

#### 后处理：拿到 api 回复后，推断如下信息并填写
- 视频名称：[填写视频全称，如：《职场新人的第一天》]
- 目标受众：[如：22-30岁职场新人、宝妈群体、数码爱好者等]
